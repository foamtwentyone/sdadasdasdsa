Глоссарий

Словарь основных терминов, используемых на портале. Поиск работает при вводе с клавиатуры — фильтрует список в реальном времени.

Бит
Минимальная единица информации, принимающая значения 0 или 1.
Голограмма
Записанная интерференционная картина двух волн, позволяющая воспроизводить трёхмерное изображение или данные.
ДНК-хранилище
Носитель информации, в котором двоичные данные кодируются последовательностью нуклеотидов синтетической молекулы ДНК.
Зеттабайт (ЗБ)
10²¹ байт. Используется для оценки объёма мировых данных.
Когерентность (квантовая)
Время, в течение которого квантовая система сохраняет суперпозицию состояний.
Кубит
Квантовый бит — двухуровневая квантовая система, допускающая суперпозицию состояний |0⟩ и |1⟩.
Магнитная лента LTO
Linear Tape-Open — стандарт магнитных лент для архивного хранения данных.
Нанорешётка
Микроскопическая периодическая структура внутри материала, создаваемая лазером для записи 5D-данных.
Нуклеотид
Структурный элемент ДНК. Существует четыре вида: A, T, G, C.
Секвенирование
Определение последовательности нуклеотидов в молекуле ДНК.
Суперпарамагнитный эффект
Явление спонтанного перемагничивания малых магнитных доменов, ограничивающее плотность записи на HDD.
Фемтосекундный лазер
Лазер, генерирующий импульсы длительностью 10⁻¹⁵ с; применяется для 5D-записи в кварцевом стекле.
Фотополимер
Светочувствительный полимер, изменяющий свойства под действием лазерного излучения; используется в голографических носителях.
